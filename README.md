# 月影解夢所 · Oneiric Oracle

「夢境解碼與視覺化」網頁工具：輸入昨晚的夢境，讓神秘又一本正經的占卜師 AI 為你解析潛意識玄機、開立今日荒誕運勢處方，生成專屬超現實主義夢境插畫，並一鍵排版輸出高清神諭圖卡（PNG）。

## 功能特色

- **雙模式解夢引擎**
  - **星象演算模式（免金鑰・開箱即用）**：內建繁體中文玄學語料庫與超現實 Canvas 繪圖引擎，會根據夢境關鍵元素（貓、金魚、牙齒、捷運、販賣機、飛行、大海、時鐘等）即時演算解夢並繪製專屬超現實插畫。
  - **Gemini AI 即時模式**：填入 Gemini API Key（透過 `.env` 或網頁設定面板），即可呼叫 `gemini-2.5-flash` 進行深度客製化神秘幽默解夢，並透過 `gemini-2.5-flash-image` 生成真實 AI 超現實夢境插畫。
- **四種超現實視覺畫風**：達利融化夢境、馬格利特超現實、浮世繪星辰、銅版畫塔羅。
- **神諭圖卡工作室**：提供「神秘塔羅牌」、「午夜美術館海報」、「復古神秘學日報」三種 1080×1660 高清圖卡版型，即時預覽並一鍵下載 PNG。
- **夢境檔案館**：自動保存最近解讀的夢境紀錄於瀏覽器本地儲存，隨時回顧或重新輸出圖卡。

## 啟動方式

需要 Node.js 20+（無需安裝任何第三方套件）：

```bash
cd dream-decoder
npm start
```

啟動後請開啟瀏覽器前往：`http://localhost:3456`
